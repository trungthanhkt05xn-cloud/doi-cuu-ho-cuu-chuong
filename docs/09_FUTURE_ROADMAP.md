# Future Roadmap

Không triển khai trước khi MVP core loop được playtest.

## V1.1 / V1.x (sau V1.0 final, chưa làm)
- thêm mission variety (groups-in-scene cho Unlock / Path / Rescue);
- thêm zone;
- thêm animal avatars (V1.0 đã có Sóc, Rùa, Thỏ);
- sound phong phú hơn (vẫn nhẹ, không nhạc nền nặng);
- animation polish;
- adaptive learning tốt hơn (dùng dữ liệu `assisted` = đúng nhờ gợi ý).

## V2+
- game world phong phú hơn, có thể 2.5D;
- chỉ nghiên cứu 3D khi playtest chứng minh tạo giá trị;
- graphics/audio nâng cao;
- cloud/profile system chỉ khi thực sự cần.
Không khóa tech stack tương lai.

## Phase 2
- PWA / Add to Home Screen;
- offline;
- nhiều mission hơn;
- daily challenge nhẹ;
- collectible;
- parent summary đơn giản.

## Phase 3
Math modules:
- cộng/trừ;
- chia;
- word problem;
- phân số;
- hình học;
- logic.

## Phase 4
- profile nhiều trẻ trên cùng thiết bị;
- sync cloud nếu thực sự cần;
- teacher/parent dashboard;
- content authoring.

## Expansion principle
Game engine nên mở rộng bằng:
- content modules;
- mission definitions;
- learning module;

không phải copy toàn bộ game cho từng môn toán.
